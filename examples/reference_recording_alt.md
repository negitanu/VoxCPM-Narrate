# 参照声音の録音スクリプト（別バリエーション）

本編 (`reference_recording.md`) より少しだけ柔らかめの言い回しです。  
尺は同様に **約20秒** を想定しています。

## 読み上げ本文

こんにちは。これは、音声クローン用の短い録音サンプルです。  
自然な口調で、無理のない速さで話します。  
ポイントは、はっきり発音することと、文の区切りで少し間を取ることです。  
準備ができたら、本番の台本読み上げに進みましょう。  
録音は、これで終了します。

## 使い方

```zsh
# 録音したファイルを配置
cp /path/to/recording.wav workspace/source.wav

# 合成
./generate_speech.zsh
```
