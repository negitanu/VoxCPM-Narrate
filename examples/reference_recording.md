# 参照声音の録音スクリプト

VoxCPM2 の Voice Cloning 用に、**15〜25秒程度**のきれいな発話を録るための台本です。  
この内容を普通の速さで読み上げて録音し、`workspace/source.wav`（または `.ogg`）として使えます。

## 録音のコツ

- 静かな部屋で、マイクから口元まで **20〜30cm** 程度
- **1テイク通し**で読む（言い直したら最初から録り直す）
- 大声・ささやき・極端な抑揚は避ける
- 目標尺: **約20秒**（短すぎる / 1分超は非推奨）
- 推奨形式: **WAV（48kHz または 16kHz、モノラル）**
- 保存先の例: `workspace/source.wav`

```zsh
# 録音後
cp ~/Desktop/reference.wav workspace/source.wav
./generate_speech.zsh --dry-run
```

## 読み上げ本文（これだけ読む）

それでは、参照用の音声サンプルを録音します。  
落ち着いた声で、はっきりと話します。  
今日は、仕事の進め方について、短い例をお話しします。  
まず現状を確認し、次に目指す姿を考え、最後に小さな一歩から始めます。  
以上です。ご清聴ありがとうございました。

## 文字数目安

| 項目 | 目安 |
|------|------|
| 文字数 | 約 140 字 |
| 読み上げ時間 | 約 18〜25 秒 |
| 用途 | `workspace/source.*` 参照声音 |

## うまく録れないとき

- **早口になる** → 句点のたびに一拍置く  
- **ノイズが多い** → エアコン・PCファンから離れる、近接マイクを使う  
- **声が遠い** → マイクを近づけ、ゲインを上げすぎない（割れ防止）  
- **クローンの声が安定しない** → この台本を同じ条件でもう一度録り直す  

別バリエーションが必要な場合は `examples/reference_recording_alt.md` も参照してください。
