台本からナレーション音声を生成

台本を分割して音声を生成し、箇所ごとに読み方の編集・再生成・試聴・採用ができます。採用した音声は WAV または ZIP で保存できます。

台本を入力するかファイルを取り込み、入力形式を選択してください。「分割を確認」で内容を確認し、「制作を保存して生成画面へ」を押してください。保存だけでは音声は生成されません。

  1. 1. 台本と設定を保存
  2. 2. 音声を生成・確認
  3. 3. WAV・ZIPで保存

1. 台本を入力

話し方と参照音声

話し方を選択し、必要に応じて指示を編集してください。声質を指定する場合は、参照音声を録音するか音声ファイルを選択してください。参照音声なしでも生成できます。

この例文を選んだ話し方で読んでください。自由に編集できます。制作する台本は変更されません。静かな場所で5〜30秒を目安に録音してください。

参照音声は未選択です。

例文は仮入力です。録音を聴き、言い間違い・省略・途中で切れた部分も実際の発話に合わせてください。

    生成と採用の違い

    初回生成は検査に合格すると自動採用されます。個別の再生成は候補を追加します。候補を試聴して「採用」を押すと、全文音声に反映されます。

    制作の保存・複製・全て再生成

    途中の状態を残すにはプロジェクト ZIP を保存してください。全て再生成は全箇所を作り直し、全件合格後に一括採用します。

    1. 修正する箇所を選択

    該当するセグメントはありません。

    チェックボックスは試聴生成の対象、本文のクリックは編集対象の選択です。

    読み変換・話し方・文間を調整

    編集の保存だけでは音声は変わりません。候補を生成し、試聴してから採用してください。

    3. 候補を試聴して採用

    音声を聴いて改善提案

    採用中の音声と本文を選択した外部サービスに送信します。提案は自動で採用されません（制作あたり最大50回）。

    読み間違いを直す・辞書に登録する

    読みを入力し、文中で試聴してから登録できます。「次の制作でも使う」を選ぶと共通辞書に蓄積します。候補は簡易抽出のため、通常の語が含まれる場合や見落としがあります。

    登録済みの読みを直接編集する

    登録は次の生成から反映されます。既存の音声は候補を再生成して採用してください。共通辞書は新しい制作にコピーされ、この制作の読みを優先します。

    完成音声を書き出す

    すべてのセグメントを生成・採用すると書き出せます。

    原音 WAV音量・間を整えた WAV原音・台本・条件 ZIP仕上げ音声・測定結果 ZIP

    仕上げは −16 LUFS を目安に小さい音量を補います。すでに十分な音量は極力維持し、ピークを保護します。3秒以上の音声と ffmpeg が必要です。原音は保持されます。

    外部 AI 評価：OpenRouter / Azure OpenAI Service

    API キーはこのタブのメモリ内だけで扱い、制作データには保存しません。サーバーの環境変数も利用できます。

    Azure の接続設定

    サーバーの .env に AZURE_OPENAI_ENDPOINT（リソースURL）を設定し、再起動してください。API キーは上の入力欄、または AZURE_OPENAI_API_KEY で指定できます。

    テキスト評価と音声評価には、それぞれ利用するデプロイ名を入力してください。音声評価は音声入力対応のデプロイが必要です。OpenRouter のモデル一覧は使用しません。

    環境変数での既定値：AZURE_OPENAI_TEXT_DEPLOYMENT / AZURE_OPENAI_AUDIO_DEPLOYMENT
